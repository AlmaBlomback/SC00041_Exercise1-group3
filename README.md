## Purpose 
The purpose of the python script `analyze_text.py` is to analyse the text components of a given textfile and calculate the number of characters and of those how many are uppercase. 
## Instructions for Running the Script

To use the repository, first clone it by using: 
```bash
git clone https://github.com/AlmaBlomback/SC00041_Exercise1-group3.git
```
Run the code using: 
```bash
python analyze_text.py
```

## Expected output
The script will print out a table of the number of characters, the number of uppercase characters and the procent of the characters that are uppercase for each line in the text file.
